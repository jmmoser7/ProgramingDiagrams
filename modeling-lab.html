A small, real 3D workbench.

Pick a creation command. Click CPlane points or type coordinates in the command bar. XYZ is CPlane space; prefix w for world or @ for relative. Ctrl+click starts Elevator; type the CPlane-normal distance or pick the elevated point. Elev sets the CPlane offset.

Box: two base corners, then height. Shift squares the base. Cube: equal edges from two corners. Polyline: vertices, Enter finish; Undo removes the last; Close after three. SrfPt: three corners + Enter, or four corners. Snaps and numeric input allow noncoplanar corners.

Navigation: RMB orbits Perspective; Shift+RMB pans. RMB pans parallel views. Ctrl+RMB zooms vertically. Ctrl+Shift+RMB orbits about geometry under the press, or the existing target on a miss. Wheel zooms at the cursor; Ctrl+wheel uses center. ZE fits all; ZS fits selected; Set target explicitly picks a new camera target. Middle click opens recent commands.

Selection: click replaces; Shift adds; Ctrl removes. Drag empty space left → right to enclose; right → left to cross. Ctrl+Shift picks components of the visible target type. Locked/hidden/filtered objects are excluded. Group selection carries unlocked visible members.

Transform: select objects/components; drag colored Gumball tips or rotation rings. Click a handle then type its numeric value in the inspector. Move/rotate/scale buttons switch modes. XYZ applies uniform scale or equal XYZ movement. Escape rolls back a live transform. Camera navigation never enters geometry history.

Precision: pixel-based End, Mid, Center and true 3D Intersection snaps; Project is explicit. Shift inverts Ortho, default 45°. Tab locks the current 3D direction and persists through vertices; Tab again releases. SmartTrack captures a snapped point after 450 ms and offers CPlane-parallel guides; last four references survive picks. No curved primitives: tangent/curve snaps are unavailable.

Blocks: select whole geometry → Block; instances reference the same immutable definition. Insert uses a point. Nested blocks and definition editing are outside this first version. Save JSON downloads a versioned document; Open validates before replacing. New is undoable. No automatic external writes.

Surfaces use a triangle or tessellated bilinear patch, boxes use polygon meshes. Component edits can warp them; no Rhino NURBS, booleans, topology healing, native .3dm round-trip, occluded-selection menu or topology loops.
